Cómo preparar una plantilla nueva

Escribe el documento completo en Word: membrete, cuerpo y las variables donde correspondan, con dos llaves alrededor exactas del nombre — {{ '{{ alumno_nombre }}' }}. Guarda como .docx y súbelo en "+ Nuevo tipo". Para una lista de varios profesores (ej. todo el comité tutorial), usa un bucle: {{ '{% for p in comite_miembros %}' }} {{ '{{ p.nombre }}' }} {{ '{% endfor %}' }}.

¿No sabes cómo se ve una plantilla ya lista? Descarga el oficio de comité tutorial — es una plantilla real, en uso, con el membrete intacto y variables ya escritas en el cuerpo.
